Komponen Sistem

6 Fitur Utama Sistem

Setiap fitur dirancang dalam modul dengan pola arsitektur yang bersih, memisahkan tanggung jawab secara jelas antar lapisan aplikasi.

📷

Barcode Scanner

Pemindaian real-time via kamera smartphone menggunakan html5-qrcode (ZXing engine). Mendukung EAN-13, CODE-128, QR Code, UPC. Debounce 3 detik per barcode unik, plus fallback input manual.

🧊

3D Viewer & AR

Visualisasi model .glb interaktif menggunakan Google Model Viewer. Mode Augmented Reality via WebXR API (Android) dan Quick Look (iOS). Superimposisi objek 3D pada permukaan nyata secara real-time.

☁️

Cloud Database

Backend-as-a-Service menggunakan Supabase (PostgreSQL). Lazy client initialization, pola Repository, async/await. Object Storage untuk aset .glb dan poster produk dengan nama file unik berbasis timestamp.

⚙️

Panel Admin

Manajemen produk CRUD penuh: tambah, edit, hapus, pencarian real-time tanpa request jaringan. Statistik produk dinamis. Upload drag-and-drop untuk aset 3D dan gambar poster.

🏷️

Generator Barcode

Render barcode CODE128 ke SVG menggunakan JsBarcode. Konfigurasi ukuran bar secara real-time, pratinjau langsung. Ekspor PNG via Canvas API dengan nama & harga produk. Cetak multi-label ke printer fisik.

📱

Progressive Web App

Instalasi ke homescreen tanpa app store. Mode offline parsial via Service Worker. Arsitektur Jamstack: distribusi statis via CDN (GitHub Pages / Netlify). Mandatory HTTPS untuk WebXR & kamera API.

Lapisan Layanan (CDN)

GitHub Pages / Netlify mendistribusikan file statis HTML, CSS, JS ke edge server secara global. Tidak ada server-side rendering — arsitektur Jamstack murni.

Library CDN eksternal: html5-qrcode · Google Model Viewer · JsBarcode · @supabase/supabase-js

Supabase JS SDK v2 — REST / Realtime API
🗄️

Lapisan Data (Supabase BaaS)

PostgreSQL Database: Tabel produk — barcode (PK), nama, deskripsi, dimensi, berat, harga, model_url, poster_url, created_at. Row Level Security (RLS) aktif.

Object Storage: Bucket produk-assets — /models/*.glb · /posters/*.jpg — URL publik untuk akses langsung di client.

◈ Tabel: produk  ·  PostgreSQL (Supabase)
Kolom Tipe Data Constraint Keterangan
id uuid PRIMARY KEY Identifikasi unik internal — gen_random_uuid()
barcode text NOT NULL UNIQUE Kode barcode produk fisik — primary lookup key
nama text NOT NULL Nama produk yang ditampilkan di UI
deskripsi text NULLABLE Deskripsi panjang produk
dimensi text NULLABLE Dimensi fisik — contoh: 60×60×85 cm
berat text NULLABLE Berat produk — contoh: 8 kg
harga text NULLABLE Harga dalam format teks — contoh: Rp 1.250.000
model_url text NULLABLE URL publik file .glb di Supabase Storage
poster_url text NULLABLE URL publik gambar poster produk di Supabase Storage
created_at timestamptz DEFAULT now() Waktu produk ditambahkan ke database
Catatan keamanan: Row Level Security (RLS) diaktifkan pada seluruh tabel. Operasi write dibatasi untuk akun administrator terotentikasi. Model Repository pada database.js menggunakan Lazy Client Initialization — Supabase client hanya dibuat saat pertama kali dibutuhkan.

Kesimpulan & Saran

Kesimpulan

Empat poin kesimpulan utama dari analisis, implementasi, dan pengujian sistem AR Produk Scanner.

✅ Scan Barcode 100% Akurat

Sistem pemindaian barcode berbasis web berhasil diimplementasikan dengan tingkat keberhasilan deteksi 100% (5/5 sampel). Fallback input manual terbukti efektif saat pemindaian optik tidak memungkinkan.

🧊 Visualisasi 3D & AR Berhasil

Integrasi model .glb dengan Google Model Viewer berhasil merender 5 produk furnitur (14–50 MB) dengan kualitas baik. Mode AR berjalan stabil via Google Scene Viewer di dua kondisi ruangan berbeda.

🏷️ Panel Admin 100% Fungsional

Seluruh 12 skenario pengujian panel admin lulus: CRUD produk, upload aset ke Supabase Storage, pencarian real-time, generator barcode, download PNG, dan cetak label multi-copy.

☁️ Jamstack Efektif untuk UMKM

Arsitektur Jamstack dengan Supabase BaaS terbukti efisien — mengelola siklus produk dari input data hingga AR tanpa infrastruktur server kompleks. Solusi hemat biaya untuk digitalisasi UMKM Indonesia.

💡 Saran Pengembangan
Offline Mode
Implementasi Service Worker penuh untuk cache data produk saat koneksi tidak stabil.
Optimasi 3D
Pipeline otomatis kompresi .glb via gltf-transform atau Draco — target <10 MB.
Autentikasi
Tambah Supabase Auth untuk panel admin — hanya pengguna berwenang yang bisa akses CRUD.
Import Massal
Fitur import produk via CSV/Excel untuk migrasi katalog yang sudah ada ke sistem baru.
Analitik
Integrasi sistem analitik: barcode paling sering dipindai, durasi sesi AR, conversion rate.
ML Vision
TensorFlow.js untuk pengenalan produk dari foto — tanpa barcode fisik pada kemasan.
